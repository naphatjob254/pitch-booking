# J MATCH ARENA

เว็บจองสนามฟุตบอลและบอร์ดหาคนเตะบอล เขียนด้วย **Go** + **MySQL/MariaDB**

## ฟีเจอร์

- สมัครสมาชิก / เข้าสู่ระบบ (เก็บรหัสผ่านด้วย **bcrypt**)
- สองบทบาท: `user` และ `admin` (หน้าแอดมินเข้าได้เฉพาะ admin)
- ข้อมูลที่มีเจ้าของ แก้/ลบได้เฉพาะเจ้าของ: โพสต์หาคนเตะ, การจองสนาม, รีวิวสนาม
- ฟอร์ม: สมัคร, ล็อกอิน, สร้าง/แก้โพสต์, จองสนาม, รีวิว
- หน้าผู้ดูแลระบบ: ลบโพสต์ อนุมัติ/ลบการจอง ลบรีวิว

## การป้องกัน

SQL Injection (prepared statements) · XSS (`html/template` + CSP) · CSRF token ทุกฟอร์ม POST ·
session cookie เข้ารหัส + `HttpOnly` + `SameSite` · เช็กสิทธิ์/เจ้าของฝั่งเซิร์ฟเวอร์ ·
จำกัดล็อกอินผิด 5 ครั้ง/10 นาที · ตรวจข้อมูลที่รับเข้า · transaction กันแย่งที่นั่ง ·
UNIQUE กันจองซ้ำ · security headers · จำกัดขนาด request

## โครงสร้างโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `main.go` | เริ่มโปรแกรม, เส้นทาง (routes), session/CSRF, middleware, handler ทั้งหมด |
| `db.go` | เชื่อมต่อฐานข้อมูล, **สร้างตารางอัตโนมัติ**, โมเดลข้อมูล, คำสั่งค้นหาที่ใช้ร่วมกัน |
| `ui.go` | รวมหน้าเว็บทั้งหมดเป็นชุดเทมเพลต |
| `ui_*.go` | หน้าเว็บแต่ละหน้า (เก็บ HTML เป็นข้อความในไฟล์ Go) |
| `static/` | รูปภาพ (`logo.png`, `7.jpg`, `9.jpg`, `11.jpg`) และ `app.js` |

## วิธีรัน

1. ติดตั้ง Go และ MySQL/MariaDB (เช่น XAMPP) แล้วสร้างฐานข้อมูลเปล่า
   ```sql
   CREATE DATABASE pitch_booking CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```
   ตารางและสนามตัวอย่าง 3 สนามจะถูกสร้างให้เองเมื่อรันโปรแกรมครั้งแรก
2. คัดลอก `run.example.bat` เป็น `run.bat` แล้วแก้ `SESSION_KEY` (และ `DB_DSN` ถ้าไม่ใช่ค่าเริ่มต้น)
3. รัน `run.bat` หรือ `go run .` แล้วเปิด http://localhost:8080
4. สร้างแอดมินคนแรก (ครั้งเดียว)
   ```
   go run . create-admin <ชื่อ> <เบอร์โทร> <รหัสผ่านอย่างน้อย 8 ตัว>
   ```

## ตัวแปรสภาพแวดล้อม

| ตัวแปร | ความหมาย |
|---|---|
| `SESSION_KEY` | คีย์ลับเข้ารหัส session (ยาว ≥ 32 ตัว) ถ้าไม่ตั้งจะสุ่มชั่วคราว |
| `DB_DSN` | การเชื่อมต่อฐานข้อมูล (ค่าเริ่มต้น `root:@tcp(127.0.0.1:3306)/pitch_booking?charset=utf8mb4`) |
| `PORT` | พอร์ตของเว็บ (ค่าเริ่มต้น 8080) |
| `COOKIE_SECURE=1` | ส่ง cookie เฉพาะ HTTPS (เปิดเมื่อใช้ผ่าน tunnel/โฮสต์จริง) |
| `TRUST_PROXY=1` | เชื่อ header IP จาก proxy (เปิดเมื่ออยู่หลัง Cloudflare/ngrok) |

> ห้ามอัปโหลด `run.bat` หรือไฟล์ที่มีคีย์จริงขึ้น GitHub (ถูกกันไว้ใน `.gitignore` แล้ว)
